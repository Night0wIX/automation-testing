## Варіант 11: `toRoman(value: number): string`

Перетворює ціле число з діапазону **1–3999** на римський запис у канонічній формі (із субтрактивними парами `IV`, `IX`, `XL`, `XC`, `CD`, `CM`).

| Вхід                     | Результат                     |
| ------------------------ | ----------------------------- |
| `1`                      | `I`                           |
| `1994`                   | `MCMXCIV`                     |
| `3999`                   | `MMMCMXCIX`                   |
| `0`, `4000`, `-5`        | `RangeError('OUT_OF_RANGE')`  |
| `3.5`, `NaN`, `Infinity` | `TypeError('INVALID_NUMBER')` |

Тести згруповано за категоріями: коректні дані, межові значення (1, 3999 та сусідні 0, 4000), некоректні дані з винятками.
